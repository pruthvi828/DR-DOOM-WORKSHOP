## 🚀 Mission 0: Quick Start

### 1. Run Setup
```powershell
.\setup.ps1
```

### 2. Add Groq API Key
Open `.env` and paste your key from [console.groq.com/keys](https://console.groq.com/keys):
```env
GROQ_API_KEY=gsk_your_key_here
```

### 3. Launch App
```powershell
.\run.ps1
```
Open `http://localhost:1420` in your browser!
